# Yomi's Universe

Build a world-class, award-winning personal website for **Yomi Onalaru** using **Next.js 15, React, TypeScript, Tailwind CSS, Framer Motion, GSAP, shadcn/ui, Vercel**, and modern best practices. The experience should feel like entering my universe—not a portfolio, but an immersive digital headquarters similar in quality to Apple, Stripe, Linear, and Nothing.

## Creative Direction

The first impression should immediately communicate:

"Creative Director. Entrepreneur. Building the future of business for creatives."

The site should feel cinematic, premium, minimal, interactive, and emotionally engaging with smooth page transitions, subtle 3D depth, premium typography, glassmorphism, dynamic lighting, micro-interactions, elegant scroll animations, animated gradients, and immersive storytelling.

Use a matte black background with tasteful gold accents and lots of breathing space.

Every section should feel intentional.

This is not a template.

Design something memorable.
